# VRP Panama

Solving a vehicle routing problem in Panama City with a genetic algorithm.

A truck leaves a depot in Albrook, visits a set of stops around the city, and returns.
The genetic algorithm searches for the shortest route.

This is groundwork for a thesis on positioning humanitarian aid stations after an
earthquake in Panama. It is inspired by the AnyLogic Cloud model
["Vehicle Routing Problem Using Genetic Algorithms"](https://cloud.anylogic.com/model/3437db48-cfb1-4fcd-8548-31ac5d15cfe2) by Felipe Haro.

## Plan
1. Python: build the genetic algorithm step by step (one file per lesson)
2. AnyLogic: rebuild it as a visual simulation on a map of Panama City
3. Extend toward aid-station placement

## Run
```
python3 lesson1_setup.py
```
